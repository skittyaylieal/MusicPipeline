PROFILES:

To add values to the profile file, go to the Profiles folder
you will need to edit the definition of the Profile class in Profile.cs, and the DefaultProfiles.cs DefaultProfile object

In future: let you choose a default profile that is inherited from when creating new profiles
and let you inherit from any profile

	Colours:
	Supports all colours the website does, all ANSI
	Colour Guide:
	https://color-palette.hexdocs.pm/ansi_color_codes.html
	ColourGuide.txt
	Use the new Gadgets/Colours.py to convert a given hex code into the closest ansi

	use 203 for error
	76 for success
	145 for debug
	111 for cookies, general or info
	213 for Orchestrator
	177 for LibraryScanner
	112 for Handler
